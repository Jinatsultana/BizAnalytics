# GitHub Upload Guide — Clean Fresh Upload

Follow these steps exactly to delete the old repo content and upload a clean version.

---

## Step 1 — Delete the old repository (cleanest approach)

1. Go to your repo on GitHub
2. Click **Settings** (top right of the repo)
3. Scroll all the way down to **Danger Zone**
4. Click **Delete this repository**
5. Type the repo name to confirm → Delete
6. Go to github.com → click **New** → recreate the repo with the same name
7. Keep it **Public**, add NO README or .gitignore (we have our own)

## Step 5 — Push to GitHub using Git Bash / terminal

Open Git Bash inside your project folder and run these commands one by one:

```bash
git init
git add .
git commit -m "feat: production-grade pipeline with RFM, CLV, churn analysis"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git push -u origin main
```

Replace YOUR_USERNAME and YOUR_REPO_NAME with your actual GitHub details.

## One important note about config.py

Before pushing, open config.py and make sure this line has a placeholder,
not your real server name:

```python
SQL_SERVER = r"YOUR_SERVER\SQLEXPRESS01"   # <-- keep this as placeholder
```

Never push your real server name or any credentials to a public GitHub repo.
